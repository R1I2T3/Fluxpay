# Landing-page media

## Original FluxPay film

cross-border-wallet.mp4 and cross-border-wallet-mobile.mp4 (and matching JPEG posters)
are original, code-rendered FluxPay motion graphics. The homepage transfer section loads
the landscape or portrait cut for the viewport, pauses it off-screen, and provides a pause control.
See scripts/media/README.md at the repository root for source and regeneration instructions.

wallet-possibility-loop.mp4 and wallet-journey-loop.mp4 are original six-second background
loops for the “Life, meets possibility.” and “Go where life takes you.” sections respectively.
They show illustrative international wallet transfers, have matching JPEG poster fallbacks,
and share the homepage's motion controls. No real customer data or external video service is used.
